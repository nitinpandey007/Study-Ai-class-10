# StudyAI Class 10 V4
Mobile-friendly AI study assistant.
Features: chapter-by-name AI help, multiple photo/PDF upload, whole chapter, notes, MCQs, Q&A and tests.

Render:
- Runtime: Node
- Build: npm install
- Start: npm start
- Environment variable: OPENAI_API_KEY
- Optional: OPENAI_MODEL (defaults to gpt-5.6)
Never put your API key in GitHub.
